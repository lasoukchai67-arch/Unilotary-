# ວຽກປະຈຳວັນ ສຳລັບທີມແອັດມິນ ແລະ ການເງິນ

## ສິດຂອງແຕ່ລະຕຳແໜ່ງ

| ຕຳແໜ່ງ (role) | ເຮັດໄດ້ |
|---|---|
| `admin` | ທຸກຢ່າງ: ສ້າງ/ປິດ/ຍົກເລີກງວດ, ເລກອັ້ນ, ປ້ອນ ແລະ ຢືນຢັນຜົນ, KYC, ຜູ້ໃຊ້, ຕັ້ງຄ່າ |
| `finance` | ອະນຸມັດ/ປະຕິເສດ ການຖອນເງິນ ແລະ ລາງວັນຍອດໃຫຍ່, ເບິ່ງລາຍງານ |
| `auditor` | ເບິ່ງໄດ້ທຸກໜ້າ ແຕ່ແກ້ຫຍັງບໍ່ໄດ້ |
| `agent` | ຂາຍແທນລູກຄ້າຜ່ານແອັບ, ໄດ້ຄ່າຄອມຕາມ % ທີ່ຕັ້ງໄວ້ |

## ທຸກງວດ

1. **ສ້າງງວດລ່ວງໜ້າ** (ໜ້າ ງວດ → ສ້າງງວດ): ເລກງວດ, ວັນທີອອກ, ເວລາເປີດຂາຍ ແລະ ປິດຂາຍ, ອັດຕາຈ່າຍ ແລະ ວົງເງິນຕໍ່ເລກ ຂອງເລກ 2–6 ໂຕ ຕາມປະກາດຂອງລັດວິສາຫະກິດ. ລະບົບເປີດ ແລະ ປິດການຂາຍເອງຕາມເວລາ.
2. **ລະຫວ່າງຂາຍ** (ໜ້າ ຄວາມສ່ຽງ): ເບິ່ງເລກທີ່ຂາຍໄດ້ຫຼາຍ, ຖ້າຈຳເປັນ ໃຫ້ຫຼຸດວົງເງິນ, ຫຼຸດອັດຕາຈ່າຍ (ເລກອັ້ນ) ຫຼື ປິດເລກ. ມີຜົນທັນທີກັບການຊື້ຄັ້ງຕໍ່ໄປ.
3. **ຫຼັງອອກລາງວັນ:**
   - ແອັດມິນຄົນທີ 1 ປ້ອນຜົນ 6 ໂຕ.
   - ແອັດມິນຄົນທີ 2 **ພິມຜົນຊ້ຳເອງ** (ບໍ່ເຫັນເລກທີ່ຄົນທີ 1 ປ້ອນ) ແລ້ວກົດຢືນຢັນ. ຖ້າເລກບໍ່ກົງ ລະບົບບໍ່ຍອມ.
   - ເມື່ອຢືນຢັນ: ລະບົບຕັດສິນທຸກບິນ, ໂອນລາງວັນທີ່ບໍ່ເກີນ `payout_auto_limit` ເຂົ້າກະເປົາທັນທີ, ສົ່ງແຈ້ງເຕືອນ, ແລະ ໂອນຄ່າຄອມໃຫ້ຕົວແທນ.
   - ຖ້າປ້ອນຜິດກ່ອນຢືນຢັນ: ກົດ "ປະຕິເສດຜົນ" ແລ້ວປ້ອນໃໝ່. **ຫຼັງຢືນຢັນແລ້ວ ແກ້ບໍ່ໄດ້** ດັ່ງນັ້ນກວດໃຫ້ດີກັບປະກາດທາງການ.
4. **ລາງວັນຍອດໃຫຍ່** (ໜ້າ ລາງວັນ): ຝ່າຍການເງິນກວດບິນ ແລະ ຕົວຕົນຜູ້ຖືກ ແລ້ວອະນຸມັດ.
5. **ລາຍງານງວດ:** ດາວໂຫຼດ CSV ເພື່ອສົ່ງລັດວິສາຫະກິດ ແລະ ກວດຍອດກັບທະນາຄານ.

ຖ້າງວດຖືກເລື່ອນ ຫຼື ຍົກເລີກ: ກົດ "ຍົກເລີກງວດ" ພ້ອມເຫດຜົນ → ທຸກບິນຖືກຄືນເງິນເຂົ້າກະເປົາອັດຕະໂນມັດ.
