# ກວດກ່ອນເປີດໃຊ້ຈິງ (Go-live checklist)

ໂຄດໃນ repository ນີ້ເຮັດວຽກຄົບໃນໂໝດທົດລອງ. ລາຍການລຸ່ມນີ້ແມ່ນສິ່ງທີ່ **ຕ້ອງເຮັດໃຫ້ຄົບກ່ອນຮັບເງິນແທ້ຈາກລູກຄ້າ**. ໝາຍ ✅ ເມື່ອສຳເລັດ.

## ກົດໝາຍ ແລະ ສັນຍາ

- [ ] ໄດ້ໃບອະນຸຍາດຕົວແທນຈຳໜ່າຍຫວຍພັດທະນາ ແລະ ອະນຸຍາດຂາຍອອນລາຍ
- [ ] ຢືນຢັນອັດຕາຄ່າຄອມ, ອັດຕາຈ່າຍລາງວັນ, ວົງເງິນ/ເລກອັ້ນ ແລະ ຮູບແບບລາຍງານ ກັບລັດວິສາຫະກິດ
- [ ] ຕົກລົງວ່າໃຜເປັນຜູ້ຈ່າຍເງິນລາງວັນ ແລະ ການຫັກລົບເງິນກັບລັດວິສາຫະກິດ (ລະບົບຈ່າຍເຂົ້າກະເປົາກ່ອນ ແລ້ວຫັກລົບພາຍຫຼັງ)
- [ ] ສັນຍາ merchant ກັບທະນາຄານ / LAPNet ແລະ ການອະນຸຍາດຈາກທະນາຄານແຫ່ງ ສປປ ລາວ ສຳລັບ e-wallet (ຖ້າຕ້ອງການ)
- [ ] ນະໂຍບາຍຄວາມເປັນສ່ວນຕົວ ແລະ ເງື່ອນໄຂການໃຊ້ງານ (ພາສາລາວ) ສະແດງໃນແອັບ
- [ ] ກວດວ່າການເກັບຂໍ້ມູນ KYC ແລະ ທີ່ຕັ້ງເຊີບເວີ ຖືກຕາມກົດໝາຍລາວ

## ການເຊື່ອມຕໍ່ພາຍນອກ

- [ ] ຂຽນ `LapnetPayments` (`backend/src/providers/payments.ts`) ຕາມເອກະສານທະນາຄານ, ທົດສອບໃນ sandbox ຂອງທະນາຄານ (ເຕີມ, webhook, ໂອນອອກ, ຍອດບໍ່ກົງ, webhook ຊ້ຳ)
- [ ] ຕັ້ງ SMS gateway (`SMS_PROVIDER=http`), ທົດສອບກັບເບີ Unitel, LTC, ETL, Best
- [ ] ຕັ້ງ URL webhook ແລະ ລາຍເຊັນ ກັບທະນາຄານ; ຈຳກັດ IP ຂອງທະນາຄານທີ່ firewall ຖ້າເຮັດໄດ້
- [ ] ຕັ້ງ push notification (Firebase) ຖ້າຕ້ອງການແຈ້ງເຕືອນນອກແອັບ (ຕອນນີ້ມີແຈ້ງເຕືອນໃນແອັບແລ້ວ)

## ຄວາມປອດໄພ

- [ ] `NODE_ENV=production` (ລະບົບປະຕິເສດ mock provider ໃນ production ອັດຕະໂນມັດ)
- [ ] ລະຫັດຜ່ານ ແລະ secret ທຸກອັນສຸ່ມໃໝ່ (`openssl rand -hex 32`), ບໍ່ commit ໄຟລ໌ `.env`
- [ ] **ປ່ຽນ repository ເປັນ Private** (ຕອນນີ້ເປັນ public) ແລະ ເປີດ 2FA ໃຫ້ທຸກບັນຊີ GitHub
- [ ] ຈ້າງ penetration test ຈາກພາຍນອກ ແລະ ແກ້ຈຸດທີ່ພົບ
- [ ] Firewall: ເປີດສະເພາະ 80/443 (ແລະ SSH ດ້ວຍ key ຈາກ IP ທີ່ກຳນົດ)
- [ ] ແອັດມິນທຸກຄົນມີ PIN; ມີແອັດມິນຢ່າງໜ້ອຍ 2 ຄົນສຳລັບ maker–checker
- [ ] ເກັບ keystore Android ແລະ ລະຫັດໄວ້ 2 ບ່ອນທີ່ປອດໄພ

## ຄວາມພ້ອມຂອງລະບົບ

- [ ] Load test ຊ່ວງກ່ອນປິດງວດ (ເຊັ່ນ k6: 500–1,000 ການຊື້ຕໍ່ວິນາທີ) ແລະ ກຳນົດຂະໜາດເຊີບເວີ
- [ ] ສຳຮອງຂໍ້ມູນອັດຕະໂນມັດທຸກມື້ + ເກັບນອກເຊີບເວີ + ທົດລອງກູ້ຄືນສຳເລັດ 1 ເທື່ອ
- [ ] Uptime monitor ກັບ `/ready` ແລະ ແຈ້ງເຕືອນເຂົ້າ LINE/WhatsApp/Email ຂອງທີມ
- [ ] ທົດລອງງວດຈຳລອງຄົບວົງຈອນໃນ staging: ສ້າງງວດ → ຂາຍ → ປິດ → ປ້ອນ/ຢືນຢັນຜົນ → ຈ່າຍລາງວັນ → ຖອນເງິນ → ລາຍງານ
- [ ] ກວດຍອດ: ຜົນລວມ ledger = ຍອດເງິນທຸກກະເປົາ (ມີ test ກວດອັດຕະໂນມັດແລ້ວ) ແລະ ກົງກັບ statement ທະນາຄານ

## ແອັບມືຖື

- [ ] ຕັ້ງ `API_BASE_URL` ເປັນໂດເມນຈິງ ແລະ ສ້າງ APK/AAB ທີ່ເຊັນດ້ວຍ keystore ຈິງ
- [ ] ບັນຊີ Google Play Developer ($25) ແລະ Apple Developer ($99/ປີ); ກວດນະໂຍບາຍ Store ສຳລັບແອັບຫວຍ (ຕ້ອງມີໃບອະນຸຍາດ ແລະ ຈຳກັດປະເທດ)
- [ ] ທົດສອບໃນມືຖືຈິງ: Android ລຸ້ນເກົ່າ (Android 6+), iPhone, ອິນເຕີເນັດຊ້າ, ຟອນລາວສະແດງຖືກຕ້ອງ
